# Enhanced Web Interface Guide

## 🌟 新功能概覽

增強版Web介面已成功整合到現有的 Streamlit 應用中，提供以下新功能：

### ✨ 主要改進

1. **🚀 增強處理模式** - 富含上下文的文檔處理
2. **🔍 兩階段搜尋** - 智能上下文圖片檢索
3. **📊 詳細統計資訊** - 增強系統狀態監控
4. **🎯 進階結果顯示** - 多層次相似度分析

---

## 🚀 使用步驟

### 1. 啟動Web介面

```bash
cd "/path/to/Image_Rag"
streamlit run app.py
```

### 2. 文檔處理選項

上傳文檔後，你會看到兩個處理選項：

#### 🔄 Process Documents (原始模式)
- 使用原始的多模態RAG系統
- 基本的圖片和文字處理
- 適合快速測試

#### 🚀 Enhanced Process (增強模式) 
- **富含上下文的處理**
- 提取圖片周圍的文字上下文
- 識別章節標題和頁面結構
- 生成多層次的embedding

### 3. 搜尋模式選擇

增強的搜尋模式包括：

- **Enhanced** 🌟 - 兩階段上下文搜尋（推薦）
- **Hybrid** - 原始混合搜尋
- **Text** - 純文字搜尋
- **Image** - 純圖片搜尋

### 4. Enhanced搜尋設定

選擇"Enhanced"模式後，可以調整：

- **Text Results**: 第一階段文字結果數量 (5-20)
- **Image Results**: 最終圖片結果數量 (1-10) 
- **Similarity Threshold**: 相似度閾值 (0.0-1.0)

---

## 🎯 Enhanced模式特色

### 📊 搜尋統計
- **Search Strategy**: 顯示使用的搜尋策略
- **Text Candidates**: 第一階段找到的文字段落數
- **Image Results**: 最終返回的圖片數量
- **Pages Covered**: 涵蓋的頁面數量

### 🔧 增強查詢
如果系統增強了你的查詢，會顯示：
```
原始查詢: 系統架構圖
相關頁數: 5, 12, 18
相關章節: 系統設計, 架構說明
關鍵詞: 微服務, API, 資料庫
```

### 📝 文字上下文結果
顯示相關的文字段落，包括：
- 文檔名稱和頁數
- 相似度分數
- 完整文字內容

### 🖼️ 上下文圖片結果

每張圖片顯示詳細資訊：

#### 基本資訊
- 📄 文檔名稱
- 📍 頁面位置  
- 📊 相似度分數
- 🎯 上下文加成分數

#### 增強資訊  
- 📖 章節標題
- 🔍 最佳匹配方法
- 📄 周圍文字上下文
- 🧠 完整富含上下文描述

#### 多層次相似度
顯示不同匹配方法的分數：
- `clip_similarity`: 圖片-文字CLIP相似度
- `rich_text_similarity`: 富含上下文文字相似度  
- `rich_clip_similarity`: 富含上下文CLIP相似度

## 🛠️ 疑難排解

### 問題1: Enhanced搜尋不可用
**錯誤**: "Enhanced system not initialized"
**解決**: 
1. 確保使用了 **🚀 Enhanced Process** 處理文檔
2. 檢查側邊欄狀態顯示為 🟢 Ready
3. 如果失敗，重新處理文檔

### 問題2: 上下文資訊不完整
**可能原因**: PDF結構複雜
**解決**:
1. 檢查PDF是否為掃描檔案
2. 確認PDF有清楚的文字結構
3. 可能需要OCR預處理

### 問題3: 相似度分數偏低
**調整方法**:
1. 降低 Similarity Threshold (如 0.4-0.5)
2. 增加 Text Results 數量
3. 使用更具體的查詢詞
